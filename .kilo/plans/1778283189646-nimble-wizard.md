# Plan: Run Program in VS Code Built-in Browser

## Goal
Run the Haplo-Clinical project inside VS Code’s built-in Simple Browser.

## User Intent (Confirmed)
- Run **both** the backend API server and the HaploClinical frontend (haplopainter).
- **Start the dev servers** first, then open the built-in browser.

## Steps
1. **Check prerequisites** — verify `pnpm` and `code` CLI are available.
2. **Install dependencies** — `pnpm install -w` (if not already done).
3. **Initialize local SQLite DB** — `pnpm --filter @workspace/db run init-sqlite` (needed for API server).
4. **Start backend API server** — `pnpm --filter @workspace/api-server run start` (requires `DATABASE_URL=sqlite:./data/db.sqlite` or `.env.local`).
5. **Start frontend dev server** — `pnpm --filter @workspace/haplopainter run dev` (Vite default port 5173).
6. **Open VS Code Simple Browser** — use `code` CLI or VS Code command to open `http://localhost:5173` in the built-in browser panel.
7. **Verify** — confirm the app loads correctly in the Simple Browser tab.

## Risks / Open Questions
- Is `code` CLI accessible to programmatically open Simple Browser?
- Port conflicts or missing `.env.local` for API server.
- Whether `mockup-sandbox` vs `haplopainter` is the correct frontend target (README references `mockup-sandbox`, but package exists as `haplopainter`).
