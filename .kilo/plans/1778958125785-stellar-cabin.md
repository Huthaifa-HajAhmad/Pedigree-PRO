## Phase C: Medium Value (30 min)

### C1 — Add DynamicImportSpinner to export-pedigree.ts
**File:** `artifacts/ppro/src/lib/export-pedigree.ts`

The `exportPDF`, `exportPPTX`, and `exportClinicalReport` functions use dynamic imports (`await import("jspdf")`, `await import("pptxgenjs")`) which can stall for 2-5 seconds on first call with zero user feedback.

**Issue:** The `DynamicImportSpinner` component exists (`components/ui/dynamic-import-spinner.tsx`) and is already used in `ShareModal.tsx`, but the export functions are library functions (not React components), so they can't directly render JSX.

**Approach:** Add a progress callback parameter to export functions. The caller (`pedigree-canvas.tsx` `he()` wrapper or RibbonToolbar) already manages `exportingFormat` state — extend it to show a loading message during the dynamic import phase.

**Files:** `lib/export-pedigree.ts` (add optional `onProgress?: (msg: string) => void` callback), `pages/pedigree-canvas.tsx` (pass progress handler that updates `exportingFormat` to show import phase).
