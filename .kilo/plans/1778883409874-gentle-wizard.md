# Plan to Run Pedigree PRO in Browser Mode

## Objective
Start the Pedigree PRO frontend in browser standalone mode using Vite dev server at http://localhost:4173.

## Prerequisites
- Node.js and pnpm installed
- (Optional) Rust toolchain not required for browser mode

## Steps

### 1. Install Dependencies with Workarounds
Due to known issues in the repository:
```bash
# Bypass preinstall.js failure (checks for pnpm)
pnpm install --ignore-scripts

# Build libraries to avoid TS6305 warnings
pnpm --filter @workspace/api-client-react exec tsc --build

# Install missing esbuild binary for Windows (if experiencing esbuild issues)
pnpm add -D @esbuild/win32-x64@0.27.3 --filter @workspace/haplopainter --ignore-scripts
```

### 2. Start Development Server
```bash
# Start frontend in browser mode
pnpm --filter @workspace/haplopainter run dev
```

## Expected Outcome
- Vite dev server starts at http://localhost:4173
- Application loads and is ready for use

## Troubleshooting
- **Port 4173 already in use**: Kill existing process before starting:
  ```powershell
  Get-NetTCPConnection -LocalPort 4173 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
  ```
- **ESBuild errors**: Ensure step 1.3 was executed
- **Dependency issues**: Verify node_modules is present after step 1

## Notes
- This runs in browser mode using sql.js WASM SQLite + IndexedDB persistence
- No server backend required - all data stays local
- For Tauri desktop mode, different steps would be required
